# Pack1 historical test evidence

These byte-for-byte source snapshots are test inputs, not build assets. The bee
snapshot predates the approved symmetry repair (recorded revision `03be8a6`);
the wardrobe snapshot predates its hinge repair (parent of `8ff5b2c`). Their
SHA-256 digests are pinned independently in the scoped tests. Neither test
reads Git history at runtime.

The frozen inventory records the 29 other blueprint JSON files and 88 original
or versioned schematic streams present before the bee repair. Original paths
are mapped to the later historical archive; the two repaired bee variants are
excluded. Each digest was checked against both the historical tree and the
current file when this fixture was created. The inventory itself is also
hash-pinned in the test. Archived wardrobe bytes have their own independent
inventory and pinned compressed and uncompressed hashes.

The wardrobe reconstruction proves equality of the legacy uncompressed NBT and
its metadata, not that a particular zlib version reproduces historical gzip
bytes. Existing assets and historical reports are never regenerated by these
tests.
